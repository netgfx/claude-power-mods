# claude-power-mods

A curated list of mods for Claude Code. Each mod adds a pane, a command, or a hook that changes how Claude Code looks or behaves. Follow the link to a mod's repo for its install steps.

## Git

- **[git-mod](https://github.com/netgfx/claude-git-mod)**: a `/git` side panel with the branch header, staged and unstaged files, and stashes.
- **[worktrees-manager-mod](https://github.com/netgfx/claude-worktrees-mod)**: a `/worktrees` panel for running several git worktrees in parallel, each with its own color, task, branch, and port block.

## Session monitoring

- **[session-dashboard](https://github.com/netgfx/claude-session-dashboard-mod)**: a live pane for the current session, showing prompt-cache state, tool calls, errors, and background work.

## Artifacts / assets

- **[local-artifacts](https://github.com/netgfx/claude-artifact-mod)**: a pane listing the images, documents, spreadsheets, and media created during a session, each opening in your default app.

## Agents

- **[swarm-mod](https://github.com/netgfx/claude-swarm-mod)**: run a swarm of agents from a side pane. Spawn them, watch their state and token use, answer their approvals, and message them.

## Code understanding

- **[flow-explainer-mod](https://github.com/netgfx/claude-flow-explainer)**: `/flow` and `/flow-explain` turn a scenario, question, or diff into a guided, step-by-step walk through the code.

## Terminal

- **[terminal-mod](https://github.com/netgfx/claude-terminal-mod)**: a real terminal (PTY) pane. `/trm` opens your shell in the workspace folder, with full-screen apps and colors.

## Mod management

- **[mod-manager](https://github.com/netgfx/claude-mod-manager)**: a `/mod-manager` pane that lists your installed mods and lets you update, enable, disable, or uninstall them, and add marketplaces.
